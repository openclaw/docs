# OpenClaw docs translation assets

This directory stores generated translation memory and documentation of the
publishing pipeline. English content and translation prompts are owned by
`openclaw/openclaw`; generated locale pages and translation memory are owned by
this repository.

- `<lang>.tm.jsonl` caches completed translations by workflow, prompt version,
  language, and source text hash.
- `translation-workflow.md` describes source sync, translation, and publication.
- Translation memory is generated by `scripts/docs-i18n` in the source repository.
  Do not edit it by hand.

`translate-incremental.yml` selects changed source pages after a cooldown;
`translate-all.yml` reconciles missing or changed translations weekly or on
manual request. Existing matching pages are preserved unless explicit recovery
requests retranslation.

These internal files are not translation inputs and do not need locale copies.
