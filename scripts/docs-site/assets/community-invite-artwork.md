# Community invitation artwork

`community-invite-light.webp` and `community-invite-dark.webp` were generated
with OpenAI image generation for Hannes Rudolph's OpenClaw community-banner
workshop and explicitly approved for rollout across OpenClaw's docs, website,
forum, and application on 2026-10-02. This approval covers using and distributing
these assets as part of those surfaces. No third-party photo or font is embedded.
Platform marks are rendered separately using the existing SVG icon set.

The scene has three dressed lobsters and one empty front-right chair. The pair
shares its composition and differs only in lighting and surface treatment.
